KeroKero

Description

KeroKero was a project in my second year of game development at Cambridge Regional College. The project itself was heavily inspired by The Battle Cats and features 4 stages which introduce new enemies for the player to face. Each of these stages also contains different backgrounds as well as having their own themes which can be listened to in the jukebox section of the main menu.
The gameplay consists of sending out frog units to go out and defend their portal from the enemy one. The player passively earns money and earns frog money at the end of the level which can be spent to upgrade units or how fast they get money in levels.
The 5 unique units synergise by having different functions to serve. For example, the wall frog is meant to protect the bubble frog from taking damage.

Contributions

For this project, I was the solo programmer with a team that consisted of an artist and a music producer.
List of responsibilities:

  • Set up a state machine for each unit
  • Set up Unity version control so the rest of the team could access the project
  • Made a unit upgrade system that saves unit levels between scenes
  • Playtesting and feedback gathering
  • Made a final boss on the last level
  • Implemented a debug menu for quicker testing by pressing on the red e in the main menu twice
