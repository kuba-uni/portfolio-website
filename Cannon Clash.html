Cannon Clash

Description

Cannon Clash was a project made for GBJam14 which is a game jam which lasts 10 days and limits your game to be styled like a gameboy. The game idea we ended upon was a Plants Vs. Zombies type game which pitted the player against a CPU which had access to the same towers as the player. This meant that the player had to use the 5 unique towers to counter what the CPU tried to do while the CPU tried to do the same to the player.
This design idea was reinforced by having towers which were made to have good and bad matchups. For example, the grapeshot had short range and therefore didn't work well against the mortar due to it being long ranged. It did, however, do well against anything placed in the front half of the ship.
The final version of the game consisted of 5 levels of increasing difficulty and the player started with 3 different towers and slowly unlocked more with each level.
